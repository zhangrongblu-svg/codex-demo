# Lin Avery Photography Portfolio

一个零依赖的个人摄影作品网站原型，采用高级、极简、北美商业摄影与现代编辑部风格。

## 设计方向

- 首页以全屏摄影封面建立第一印象，文字只保留一句极简定位。
- 作品页采用精选项目与瀑布流混排，让单张照片和项目故事同时成立。
- 项目故事通过轻量弹窗展示客户、地点、年份、背景与主视觉。
- 视觉以白底、灰白、黑色为主，使用少量暖砂色作为品牌注脚。
- 动效控制在入场、悬停、项目切换层面，保持克制与呼吸感。

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。
